===============================================================================
  دليل إضافة أدوات البايثون في برنامج ArcGIS Pro وطريقة ضبط المعاملات (Parameters)
  HOW TO ADD PYTHON SCRIPT TOOLS IN ARCGIS PRO & CONFIGURE PARAMETERS
===============================================================================

تحتوي هذه الحزمة على أداتين مخصصتين لبيئة ArcGIS Pro (Python 3.x):
1. export_vertices.py (أو export_vertices_arcpro.py):
   أداة تصدير بيانات قطع الأراضي وإحداثيات أركانها بنظام WGS84 بالدرجات العشرية إلى ملف CSV مع تقريب المساحة والمحيط.
2. export_cadastral_survey.py:
   أداة إجراء التقاطع المكاني (Spatial Intersection) بين طبقة الأراضي وطبقة الأحواض والقطع وتصدير مجلد مستقل لكل صاحب طلب.

-------------------------------------------------------------------------------
خطوات إضافة الأداة في ArcGIS Pro (Step-by-Step Installation):
-------------------------------------------------------------------------------
1. افتح مشروعك في برنامج ArcGIS Pro.
2. في لوحة الكتالوج (Catalog Pane) على اليمين، توجه إلى قسم Toolboxes.
3. انقر بالزر الأيمن (Right-Click) على Toolboxes واختر:
   New Toolbox (.atbx)
   قم بتسميته، مثلاً: Cadastral_Tools.atbx
4. انقر بالزر الأيمن على صندوق الأدوات الجديد (.atbx) ثم اختر:
   New -> Script
5. ستفتح لك نافذة خصائص الأداة (Tool Properties):

===============================================================================
[الأداة الأولى: تصدير أركان المضلعات - Export Polygon Vertices]
ملف السكريبت: export_vertices.py  (أو export_vertices_arcpro.py)
===============================================================================

1. في تبويب (General):
   - Name (الاسم الداخلي - بدون مسافات): ExportVerticesArcPro
   - Label (اسم الأداة الظاهر للمستخدم): تصدير أركان المضلعات WGS84
   - Description: تصدير إحداثيات الأركان والبيانات الوصفية لملف CSV

2. في تبويب (Execution):
   - أمام خانة Script File: انقر على أيقونة التصفح (Browse) واختر: export_vertices.py

3. في تبويب (Parameters - جدول المعاملات):
   أضف المعاملين التاليين بالترتيب:

   ----------------------------------------------------------------------------
   Row # | Label (Display Name)        | Name           | Data Type     | Type     | Direction
   ----------------------------------------------------------------------------
   Row 0 | طبقة المضلعات (Polygon Layer)| polygon_layer  | Feature Layer | Required | Input
   Row 1 | مجلد الحفظ (Output Folder)    | output_folder  | Folder        | Required | Input
   ----------------------------------------------------------------------------

   * في السطر الأول (polygon_layer): توجه لقسم Filter بالأسفل واختر Geometry -> Polygon.

4. انقر Save أو OK بالأسفل لحفظ الأداة.


===============================================================================
[الأداة الثانية: التقاطع المساحي وإصدار شهادات المعاملات - Cadastral Survey Intersection]
ملف السكريبت: export_cadastral_survey.py
===============================================================================

1. في تبويب (General):
   - Name: CadastralIntersectionArcPro
   - Label: فحص وتقاطع الأراضي مع الأحواض والقطع
   - Description: تقاطع مكاني مع طبقة الأحواض وتصدير ملفات Land و Areas لكل مواطن

2. في تبويب (Execution):
   - أمام Script File: انقر على Browse واختر الملف: export_cadastral_survey.py

3. في تبويب (Parameters - جدول المعاملات):
   أضف المعاملات الثلاثة التالية بالترتيب:

   ----------------------------------------------------------------------------
   Row # | Label (Display Name)              | Name        | Data Type     | Type     | Direction
   ----------------------------------------------------------------------------
   Row 0 | طبقة الأراضي/الطلبات (Land Layer)   | land_layer  | Feature Layer | Required | Input
   Row 1 | طبقة الأحواض والقطع (Basins Layer)  | areas_layer | Feature Layer | Required | Input
   Row 2 | مجلد الحفظ والمخرجات (Output Folder)| out_folder  | Folder        | Required | Input
   ----------------------------------------------------------------------------

4. انقر Save أو OK لحفظ الأداة.

-------------------------------------------------------------------------------
طريقة التشغيل والاستخدام (How to Run in ArcGIS Pro):
-------------------------------------------------------------------------------
1. انقر نقراً مزدوجاً على الأداة في Catalog Pane أو Geoprocessing Pane.
2. ستفتح لك الأداة كأداة رسمية في شريط Geoprocessing.
3. حدد العنصر المطلوب في الخريطة بأداة Select (إذا لم تحدد سيقوم بتصدير الكل مع إظهار تحذير آمن).
4. اختر الطبقات ومجلد الحفظ وانقر Run بالأسفل.
5. سيتم توليد المخرجات فوراً في المجلد بترميز UTF-8 مع BOM لقراءتها بالعربي مباشرة في Excel.
