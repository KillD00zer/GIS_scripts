===============================================================================
  دليل إضافة أدوات البايثون في برنامج ArcMap 10.x وطريقة ضبط المعاملات (Parameters)
  HOW TO ADD PYTHON SCRIPT TOOLS IN ARCMAP 10.x & CONFIGURE PARAMETERS
===============================================================================

تحتوي هذه الحزمة على أداتين مخصصتين لبيئة ArcMap 10.8 (Python 2.7):
1. arcmap code.py (أو export_vertices_arcmap.py):
   أداة تصدير بيانات قطع الأراضي وإحداثيات أركانها بنظام WGS84 إلى ملف CSV مع تقريب المساحات والمحيط.
2. export_cadastral_survey_arcmap.py:
   أداة إجراء التقاطع المكاني (Spatial Intersection) بين طبقة الأراضي وطبقة الأحواض والقطع وتصدير مجلد مستقل لكل صاحب طلب.

-------------------------------------------------------------------------------
خطوات إضافة الأداة في ArcMap (Step-by-Step Installation):
-------------------------------------------------------------------------------
1. افتح برنامج ArcMap وافتح نافذة الأدوات (ArcToolbox Window).
2. انقر بالزر الأيمن (Right-Click) على أي مجلد داخل ArcToolbox أو مسار مجلدك في Catalog.
3. اختر: New -> Toolbox (أنشئ صندوق أدوات جديد بصيغة .tbx، مثلاً: Cadastral_Tools.tbx).
4. انقر بالزر الأيمن على صندوق الأدوات الجديد ثم اختر: Add -> Script...
5. ستفتح لك نافذة معالج إضافة الأداة (Add Script Wizard):

===============================================================================
[الأداة الأولى: تصدير أركان المضلعات - Export Polygon Vertices]
ملف السكريبت: arcmap code.py  (أو export_vertices_arcmap.py)
===============================================================================

الخطوة 1 (General):
  - Name (الاسم الداخلي - بدون مسافات): ExportVerticesArcMap
  - Label (اسم الأداة الظاهر): تصدير أركان المضلعات WGS84
  - Description: تصدير إحداثيات الأركان والبيانات الوصفية لملف CSV
  - ضع علامة صح أمام [✔] Store relative path names (لحفظ المسارات النسبية)
  - انقر Next.

الخطوة 2 (Source):
  - انقر على زر التصفح (Browse) واختر الملف: arcmap code.py
  - انقر Next.

الخطوة 3 (Parameters - جدول المعاملات):
  أضف المعاملين التاليين بالترتيب الدقيق:

  -----------------------------------------------------------------------------
  رقم المعامل | Display Name               | Data Type     | Type     | Direction
  -----------------------------------------------------------------------------
  Parameter 0 | طبقة المضلعات (Polygon Layer) | Feature Layer | Required | Input
  Parameter 1 | مجلد الحفظ (Output Folder)     | Folder        | Required | Input
  -----------------------------------------------------------------------------

  * ملاحظة للمعامل 0 (اختياري): في خصائص المعامل بالأسفل، يمكنك تعيين Filter -> Geometry -> Polygon.

- انقر Finish لحفظ الأداة.


===============================================================================
[الأداة الثانية: التقاطع المساحي وإصدار شهادات المعاملات - Cadastral Survey Intersection]
ملف السكريبت: export_cadastral_survey_arcmap.py
===============================================================================

الخطوة 1 (General):
  - Name: CadastralIntersectionArcMap
  - Label: فحص وتقاطع الأراضي مع الأحواض والقطع
  - Description: تقاطع مكاني مع طبقة قطع الأحواض وتصدير ملفات Land و Areas لكل مواطن
  - ضع علامة صح أمام [✔] Store relative path names
  - انقر Next.

الخطوة 2 (Source):
  - اختر الملف: export_cadastral_survey_arcmap.py
  - انقر Next.

الخطوة 3 (Parameters - جدول المعاملات):
  أضف المعاملات الثلاثة التالية بالترتيب الدقيق:

  -----------------------------------------------------------------------------
  رقم المعامل | Display Name                   | Data Type     | Type     | Direction
  -----------------------------------------------------------------------------
  Parameter 0 | طبقة الأراضي/الطلبات (Land Layer) | Feature Layer | Required | Input
  Parameter 1 | طبقة الأحواض والقطع (Basins Layer)| Feature Layer | Required | Input
  Parameter 2 | مجلد الإخراج (Output Destination) | Folder        | Required | Input
  -----------------------------------------------------------------------------

- انقر Finish لحفظ الأداة.

-------------------------------------------------------------------------------
طريقة التشغيل والاستخدام (How to Run):
-------------------------------------------------------------------------------
1. انقر نقراً مزدوجاً على الأداة داخل الـ Toolbox لفتح واجهتها.
2. حدد الأرض أو القطعة المطلوبة في الخريطة بأداة Select (إذا لم تحدد سيقوم بتصدير الكل).
3. اختر الطبقات ومجلد الحفظ وانقر OK.
4. ستظهر نتائج التنفيذ مباشرة في نافذة Geoprocessing Results، وسيتم إنشاء الملفات بترميز UTF-8 مع BOM لفتح الأسماء العربية بشكل سليم تماماً في Excel.
